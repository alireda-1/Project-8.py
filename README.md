# User Authentication System

A secure and interactive **Python** script that simulates a user login portal, verifying credentials and providing specific error messages using advanced multi-conditional logic.

## Features
- **Case-Insensitive Match:** Utilizes the `.lower()` method to ensure user name validation works seamlessly regardless of capitalization.
- **Detailed Error Handling:** Provides precise console feedback for various login scenarios (Incorrect Password, Incorrect Name, or both wrong).
- **Multi-Conditional Logic:** Built using strict Python `if-elif-else` structures combined with the `and` logical operator for dual-credential verification.

## Technologies Used
- Python 3
